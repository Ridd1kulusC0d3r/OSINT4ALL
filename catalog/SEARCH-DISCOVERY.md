# Search & Discovery OSINT

This catalog consolidates the strongest discovery patterns surfaced by **jivoi/awesome-osint**, **Astrosp/Awesome-OSINT-List** and the existing OSINT4ALL catalogs.

## Search surfaces

| Surface | Typical analytical purpose |
|---|---|
| General search | Broad discovery and query expansion |
| National/local search engines | Jurisdiction-specific discovery |
| Meta/privacy search | Alternative indexes and result diversity |
| Document/slides search | Reports, presentations and grey literature |
| Code search | Repositories, configuration fragments and technical context |
| News/blog/forum search | Narrative, chronology and community context |
| Web archives | Deleted/changed historical material |
| Public records | Authoritative jurisdictional sources |
| Academic/grey literature | Research, attribution and technical depth |
| Geospatial search | Places, imagery and spatial corroboration |

## Query discipline

Good search is not the number of tabs opened. Record:

1. intelligence requirement;
2. search terms and variants;
3. date/language/jurisdiction constraints;
4. source type;
5. query that produced the finding;
6. negative searches that materially affect confidence.

## Discovery vs evidence

Search results are **leads**. Promote a lead to evidence only after source inspection, provenance capture and corroboration appropriate to the claim.
